# Capstone — Alloxentric Real Time Agent

Repositorio académico y técnico del proyecto Capstone de Ingeniería en Informática, desarrollado por un equipo de tres integrantes en colaboración con Alloxentric.

## Flujo de trabajo

- `main`: rama estable e integrada. No se trabaja directamente sobre ella.
- `dev/fernando`: rama de trabajo de Fernando.
- `dev/juan`: rama de trabajo de Juan.
- `dev/david`: rama de trabajo de David.
- Todo cambio hacia `main` debe ingresar mediante Pull Request.

## Estructura

- `docs/`: documentación académica, gestión, arquitectura y evidencias.
- `src/`: código fuente del proyecto.
- `tests/`: pruebas automatizadas y evidencias técnicas.
- `.github/`: plantillas y configuración de colaboración.

## Convención recomendada de commits

- `docs:` documentación
- `feat:` nueva funcionalidad
- `fix:` corrección
- `test:` pruebas
- `refactor:` refactorización
- `chore:` tareas de mantenimiento

## Proyecto

**Alloxentric Real Time Agent**

El contenido funcional, alcance, arquitectura y entregables se documentarán progresivamente durante las fases del Capstone.
